# Radiology Suite — AI Agent Instructions

## Git workflow

- Always edit directly in the root repository checkout on `main`.
- Never create or use Git worktrees, including `.claude/worktrees/`.
- Never create or switch to feature, task, or temporary branches. All work stays on `main`.
- Make the changes, run the relevant checks, then commit the completed changes directly on `main`.
- Preserve unrelated changes and include only the intended files in each commit.

Read `CLAUDE.md` for the project guide (Nix shell, commands, layering, security model).
